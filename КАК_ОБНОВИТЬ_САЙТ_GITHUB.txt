VIS OS — обновлённый публичный сайт

ЧТО В АРХИВЕ
- index.html — новая главная страница на русском.
- VIS_OS_Aurora93_Stage68_Compatibility_Center.html — HTML-прототип Aurora, на который ведут ссылки.
- CNAME — привязка домена vis-os.com для GitHub Pages.
- ПЛАН_ПРОДВИЖЕНИЯ.txt — идеи продвижения проекта.

КАК ОБНОВИТЬ СУЩЕСТВУЮЩИЙ САЙТ ЧЕРЕЗ GITHUB (НЕ СОЗДАВАЯ НОВЫЙ РЕПОЗИТОРИЙ)
1. Скачай ZIP и распакуй его на компьютере («Извлечь всё…»).
2. Открой GitHub и именно тот репозиторий, из которого уже публикуется vis-os.com.
3. Нажми Add file → Upload files (Добавить файл → Загрузить файлы).
4. Перетащи index.html, CNAME, VIS_OS_Aurora93_Stage68_Compatibility_Center.html и ПЛАН_ПРОДВИЖЕНИЯ.txt из распакованной папки в окно загрузки.
5. Если GitHub спросит о замене index.html/CNAME/прототипа — подтверди замену. Если CNAME в репозитории уже содержит vis-os.com, его можно оставить без изменений.
6. Внизу нажми Commit changes (Сохранить изменения).
7. Подожди 1–3 минуты и открой https://vis-os.com/ с Ctrl+F5. Если старая версия ещё видна, подожди немного и обнови снова.

ВАЖНО
- Загружай файлы из корня распакованной папки, а не сам ZIP и не вложенную папку целиком. index.html должен оказаться в корне публикуемого сайта.
- Не удаляй настройки Pages и не меняй DNS, если домен уже работает.
- Ссылки на прототип предполагают, что HTML-файл прототипа лежит рядом с index.html.
- Сайт и Aurora — веб-страницы. Они не являются готовым установочным ISO и не запускают нативные приложения Windows/Android/Steam.
