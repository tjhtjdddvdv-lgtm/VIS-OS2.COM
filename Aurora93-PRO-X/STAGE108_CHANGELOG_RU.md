# Stage 108 — строгая проверка аппаратного отчёта

- Планировщик загрузочного пути проверяет точную сигнатуру отчёта Stage 105.
- Для каждого используемого поля требуется ровно одно непустое значение.
- Дублированные поля больше не могут скрывать противоречивые аппаратные значения.
- При повреждённом заголовке, пустом поле или повторяющемся идентификаторе выбор EFI-пути блокируется.
- Добавлены отрицательные регрессионные тесты.

Проверено локально: синтаксис Bash и 12 сценариев теста планировщика проходят.
Тесты используют синтетические отчёты. Реальный ISO и DIGMA Citi 1804 не проверялись.
