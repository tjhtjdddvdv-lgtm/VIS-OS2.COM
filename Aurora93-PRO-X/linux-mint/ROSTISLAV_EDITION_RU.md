# VIS OS Aurora 93 PRO X — Rostislav Edition

## Базовая платформа

- Основа: Linux Mint.
- Устройство: DIGMA Citi 1804, Intel Atom x5-Z8350.
- Форм-фактор: ноутбук-планшет.
- Интерфейс: отдельная оболочка VIS OS; стандартный рабочий стол Mint не должен быть пользовательским интерфейсом финальной редакции.
- Ввод: сенсорный экран, клавиатура и тачпад. Автопереключение режимов включается только после проверки датчиков/событий устройства.

## Требование к загрузке

Обычная загрузка должна быть графической:
1. UEFI/GRUB показывает только короткий переход к системе; меню скрыто по умолчанию.
2. Plymouth показывает заставку вместо потока сообщений ядра.
3. Linux Mint запускает графическую сессию.
4. Автоматически стартует оболочка VIS OS.

Технические сообщения не удаляются: они остаются в journal и доступны для диагностики. Меню GRUB должно оставаться доступным через Esc (UEFI) или Shift (BIOS).

## Stage 110 — тихая загрузка

Установка конфигурации на уже установленной тестовой Linux Mint:

```bash
chmod +x Aurora93-PRO-X/scripts/configure_silent_boot_mint.sh
sudo bash Aurora93-PRO-X/scripts/configure_silent_boot_mint.sh
```

Скрипт:
- создаёт резервную копию `/etc/default/grub`;
- включает `quiet splash`, ограничивает вывод статуса systemd и udev;
- скрывает меню GRUB по умолчанию, сохраняя способ вызвать его вручную;
- запускает `update-grub`;
- восстанавливает резервную копию, если обновление GRUB завершилось ошибкой.

Откат: скопировать нужный файл `/etc/default/grub.visos-backup-ДАТА` обратно в `/etc/default/grub`, затем выполнить `sudo update-grub`.

## Что ещё не считается готовым

Stage 110 настраивает только графически чистую загрузку. Он НЕ создаёт готовую оболочку, не устанавливает драйверы DIGMA и не является ISO. Следующие обязательные этапы:
- интеграция существующего HTML/CSS/JS рабочего стола VIS OS в системную сессию;
- запуск оболочки вместо стандартного Mint desktop;
- Plymouth-тема с фирменным логотипом VIS OS;
- проверка тачскрина, клавиатуры, тачпада, Wi-Fi, звука, камеры, батареи и сна;
- сборка и тестирование ISO отдельно для подходящих EFI/BIOS путей.

## Разделение редакций

Rostislav Edition использует общий системный слой Aurora, но отдельные:
- название и заставку;
- профиль первого пользователя;
- обои, цветовую схему и набор закреплённых приложений;
- конфигурацию оболочки.

Пользовательская редакция DIGMA остаётся отдельной. Общие исправления можно переносить в обе сборки, персональные настройки — нет.
