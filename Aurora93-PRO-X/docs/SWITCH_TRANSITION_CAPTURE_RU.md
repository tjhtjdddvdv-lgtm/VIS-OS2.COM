# Stage 115 — мониторинг input switch и platform tablet_mode

Stage 114 опрашивал только `EVIOCGSW` на `/dev/input/event*`. Некоторые
платформенные драйверы могут публиковать текущее положение в read-only sysfs
атрибуте `tablet_mode`, даже если input switch не объявлен. Stage 115 добавляет
чтение таких атрибутов из двух представлений sysfs:

- `/sys/devices/platform/*/tablet_mode`;
- `/sys/bus/platform/devices/*/tablet_mode`.

Обычно второй путь содержит ссылки на устройства из первого; монитор разрешает
пути и удаляет дубликаты. Ссылки, ведущие за пределы переданного `--sys-root`,
не читаются. Значения `0` и `1` отображаются как laptop и tablet. Неизвестные
значения, ошибки чтения и недоступные корни отражаются как incomplete.

## Запуск на DIGMA Citi 1804

Из корня репозитория в Linux Live:

```bash
sudo python3 Aurora93-PRO-X/scripts/monitor_convertible_switch.py \\
  --interval 0.5 --duration 180 \\
  | tee VIS_OS_CITI1804_SWITCH_TRACE.txt
```

Сначала оставьте устройство в положении ноутбука примерно на 10 секунд, затем
медленно переведите экран в положение планшета и обратно. Монитор одновременно
записывает `SW_TABLET_MODE`/`SW_LID` через `EVIOCGSW` и прямые платформенные
`tablet_mode` sysfs-атрибуты. Он не читает очередь `input_event`, не забирает
события у рабочего стола и не записывает sysfs.

Отдельно можно выполнить только платформальную диагностику:

```bash
python3 Aurora93-PRO-X/scripts/probe_platform_tablet_mode.py
```

## Интерпретация

- Совпадение `laptop(0)` и `tablet(1)` с физическим движением — кандидат для дальнейшей проверки, но не подтверждение готового Auto Mode.
- `conflict`, `unknown` или `incomplete` блокируют автоматический выбор режима.
- `SW_LID` описывает крышку и сам по себе не равен hinge/tablet mode.
- Отсутствие прямого sysfs-атрибута не доказывает отсутствие датчика: возможен другой драйвер или ACPI-интерфейс.

Stage 115 только расширяет read-only диагностику. Он не включает автоматическое
переключение, не меняет Stage 101/102 UI и не подтверждает работу физического
DIGMA Citi 1804.
