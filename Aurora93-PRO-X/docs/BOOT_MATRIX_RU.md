# Матрица загрузки MULTI-UEFI

| Прошивка | Путь на ISO | Требование |
|---|---|---|
| UEFI IA32 | EFI/BOOT/BOOTIA32.EFI | Настоящий 32-битный EFI-бинарник |
| UEFI x86-64 | EFI/BOOT/BOOTX64.EFI | Настоящий 64-битный EFI-бинарник |
| Legacy BIOS | El Torito BIOS image | GRUB i386-pc и BIOS boot image |

Один EFI-бинарник не может одновременно иметь обе архитектуры. На одном ISO
можно разместить оба fallback-файла; прошивка выбирает подходящий по формату.
Secure Boot пока не заявляется. Поддержка 64-битного ядра на IA32 UEFI требует
отдельной проверки mixed-mode EFI и совместимости ядра.
