# Проверка трассы Laptop/Tablet — Stage 116

Stage 115 записывает в один файл изменения двух независимых источников:

- `SW_TABLET_MODE` из Linux input через `EVIOCGSW`;
- прямые `tablet_mode`-атрибуты платформенных устройств sysfs.

Stage 116 добавляет офлайн-валидатор `scripts/validate_convertible_trace.py`.
Он читает уже сохранённую трассу и не обращается к `/sys`, `/dev/input`, не
потребляет input-события и не меняет режим рабочего стола.

## Запуск

Из корня репозитория после записи Stage 115:

```bash
python3 Aurora93-PRO-X/scripts/validate_convertible_trace.py \
  VIS_OS_CITI1804_SWITCH_TRACE.txt
python3 Aurora93-PRO-X/tests/test_validate_convertible_trace.py
```

## Условия результата

`PASS` возможен только если в каждом снимке оба источника имеют полную
инвентаризацию, оба сообщают одинаковое состояние, а последовательность
состояний каждого источника ровно такая:

`laptop -> tablet -> laptop`

Повторные одинаковые снимки схлопываются. Дополнительное переключение,
расхождение источников, `unknown`, `conflict` или `incomplete` не принимаются.
Номера снимков должны строго возрастать, временные метки должны содержать
UTC-смещение и не идти назад.

- Код завершения `0`: трасса прошла структурную проверку и оба источника
  согласованно записали полный цикл.
- Код завершения `1`: трасса неполная или повреждена, например нет одного
  источника, отсутствует сводка или нарушен порядок снимков.
- Код завершения `2`: источники расходятся, цикл не соответствует ожидаемой
  последовательности либо файл нельзя прочитать.

Даже `PASS` означает только успешную проверку сохранённой трассы. Перед
разрешением Auto Mode требуется вручную подтвердить, что физическое движение
DIGMA Citi 1804 совпадало с записанными переходами, повторить цикл несколько
раз и проверить ложные срабатывания при обычном закрытии крышки. `SW_LID` не
считается заменой `SW_TABLET_MODE`.

Stage 116 не включает Auto Mode и не меняет Stage 101/102 UI, приложения,
четыре рабочих пространства или обои Stage 103. ISO и физическое устройство
этим этапом не тестировались.
