# VISCRAFT 0.4 — VIS OS Edition

Единый браузерный лаунчер и voxel-игра в эстетике Aurora / VIS OS.

## Быстрый запуск
1. Установи Node.js 18 или новее.
2. В этой папке выполни `npm install`, затем `npm start`.
3. Открой http://localhost:8080.

Three.js загружается с CDN, поэтому для первого запуска нужен интернет.

## Мультиплеер
Сервер Node.js обслуживает страницу, комнаты, чат, перемещение игроков и сохраняет изменения блоков в `worlds/`. Для друзей в локальной сети укажи `ws://IP-КОМПЬЮТЕРА:8080`. Для публикации в интернете нужен хостинг Node.js с WebSocket/TLS (wss://); GitHub Pages — только статический хостинг и не запускает Node.js.

## Состояние прототипа
Включены процедурный voxel-ландшафт, смена освещения, физика передвижения, базовое выживание, простые мобы, крафт, локальное сохранение правок, комнаты/чат, скины-цвета и экранное управление. Это ранний прототип: не является завершённой игрой; сетевой код не имеет аккаунтов/анти-чита и требует тестирования перед публичным использованием.
